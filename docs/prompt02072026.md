PHASE 1 — FORK AUF DEN 9.2-GUI-STAND ANGLEICHEN (nur falls nötig)
Nur wenn Phase 0 zeigt: gui-lib-Version ≠ der des installierten Systems. Ist der Fork bereits auf
Systemstand → Phase 1 überspringen und vermerken.
1. SICHERHEITSNETZ zuerst: im gui-Submodul `git branch backup/pre-9.2-merge` auf den aktuellen
   Stand (nur ein Zeiger, verändert nichts).
2. Auf den Branch: im Submodul `git checkout qt-backend` (aus evtl. detached HEAD), prüfen dass es
   dem Remote-Tip entspricht (kein unerwarteter Divergenz-Zustand; sonst STOPP).
3. Upstream: `git remote add upstream https://github.com/racket/gui` (falls fehlt),
   `git fetch upstream --tags`.
4. Ziel-Commit: der Upstream-Stand zu deinem installierten Racket 9.2 — das Release-Tag `v9.2` des
   gui-Repos, falls vorhanden; sonst der Upstream-Commit, dessen `gui-lib/info.rkt` die
   System-Version deklariert. Zielversion VOR dem Merge verifizieren.
5. MERGE (kein Rebase): `git merge <ziel>` in qt-backend. Konflikte entstehen NUR in den wenigen
   geänderten BESTEHENDEN Dateien (window/frame/canvas/platform + Backend-Auswahl-Stelle); die
   additiven wx/qt-Neu-Dateien und die ~440 unveränderten Upstream-Dateien mergen konfliktfrei.
   Konflikte so lösen, dass die Qt-Additionen + die Fixentscheidungen erhalten bleiben UND die
   System-Schnittstelle steht. Umfangreiche/uneindeutige Konflikte → STOPP, nicht raten.
6. Verifizieren: `gui-lib/info.rkt` = Systemversion; `PLT_QT=1 raco test tests/smoke.rkt` grün.
   Der Merge kann NEUE Override-Ziele mitbringen (frische public*/override*-Runden wie der
   designate-root-frame-Stub) — additiv lösen, ins Ledger.
7. draw nur bei Divergenz aus Phase 0 analog angleichen; sonst System-draw-lib.
8. Commit (zwei Repos): gui-Fork committen/pushen, Umbrella-Submodul-Zeiger auf den Merge-Commit
   nachziehen und committen.

PHASE 2 — DRRACKET AUF DEN FORK ZEIGEN LASSEN (das Tor)
1. gui-lib-Fork als verlinktes User-Paket installieren, das die System-Version ERSETZT:

2. `raco setup`, damit DrRacket gegen den Fork NEU kompiliert (behebt den installierten

   Linklet-Mismatch? Das beweist, dass der Angleich sitzt. Wenn NICHT: STOPP — dann war das
   Angleich-Ziel falsch (NICHT mit Stubs übertünchen).
