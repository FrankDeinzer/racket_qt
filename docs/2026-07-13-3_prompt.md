## Ziel (ein Thema)

`tab-panel%` von No-op-Stub auf **echt** (QTabWidget bzw. native Tab-Leiste — Struktur aus
gtk/win32 ableiten). Das ist das **letzte primitive Widget** der Breite **und** der
Schlüssel für die **Preferences-Ende-zu-Ende-Validierung**: die Kategorie-Nav des Dialogs
zieht `tab-panel%` unconditional (Block-A-Befund), daher war der echte Dialog bisher
strukturell blockiert. Fundament (§18.2/§18.3/§19/§20) steht — darauf aufsetzen.

## Phase 1 — Orakel (nativer Spiegel + Preferences-Nutzung)

- `wx/gtk/tab-panel.rkt` **und** `wx/win32/tab-panel.rkt` lesen und den vollständigen
  Kontrakt festhalten: Methoden (`append`/`delete`/`set`/`get-selection`/`set-selection`/
  `get-number`/`get-item-label`/`set-item-label` + was gtk/win32 sonst noch definieren),
  Callback-Event-Typ `'tab-panel`, und **vor allem die Struktur**: nutzen gtk/win32 die
  native Seitenverwaltung des Tab-Controls, oder eine reine **Tab-Leiste über der
  wx-eigenen Kind-Fläche** (Kinder bleiben wx-verwaltet, das native Control liefert nur
  Auswahl + Callback)? Diese Entscheidung bestimmt das **QTabWidget-vs-QTabBar-Mapping** —
  aus dem nativen Vorbild ableiten, **nicht raten**.
- Aus dem Block-A-Befund kurz verifizieren: **wie** nutzt die Preferences-Kategorie-Nav
  `tab-panel%` (welche Methoden, welche Konfiguration)? Damit die Ende-zu-Ende-Probe in
  Phase 3 gezielt trifft.

**Self-Gate Checkpoint 1:** Kontrakt + Struktur + Preferences-Nutzung klar → **GO

## Phase 2 — Implementieren (Windows)

- Neue **`wx/qt/tab-panel.rkt`**, Struktur 1:1 am nativen Vorbild (gtk/win32) — Klassen-
  Komposition, Methoden, Semantik.
- Shim-Funktionen für das native Tab-Control (mirror den bestehenden Widget-Shim-Stil,
  Debug gated hinter `PLT_QT_DEBUG`).
- **Callback `'tab-panel`:** Signal→C++-Lambda ruft **nur** `cb(ud)`; Racket liest die
  Auswahl per separatem Shim-Query. Einmal-Trampolin im Konstruktor, retained (§19).
  `QSignalBlocker` für **jede** programmatische Mutation (`set-selection`/`set`/`append`/
  `delete`), damit sie den Callback nicht re-triggert (§20).
- **`seed-size-from-native-hint`** im Konstruktor (§18.2).
- **`public*`/`override*`-Invariante (§1):** ein Container erbt mehr Maschinerie als ein
  Blatt-Control — Diskriminator = Kontrakt gegen gtk/win32, nicht raten.
- **No-op-Stub sauber ersetzen:** der `tab-panel%`-Stub in `wx/qt/platform.rkt` sitzt in
  derselben Stub-Factory, die den `set-label`-variadic-Fix von 07-08 trägt. Per
  grep/Lektüre prüfen, welche **anderen** Stub-Klassen die Factory bedient, und
  sicherstellen, dass keine davon bricht. Wirkt die Entkopplung riskant → **STOPP +
  fragen**, nicht blind schneiden.
- **Kein `exec()`/keine geschachtelte Schleife. Kein Shared-Code (`wx/common`) ohne
  Rückfrage.**
